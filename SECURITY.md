# Security

## What counts as a security issue

- A record or page that carries instructions aimed at AI agents (prompt injection).
- A link that now points to malware or a hijacked domain.
- A leaked secret: token, key or password in any file or commit.
- A flaw in `tools/` or in the MCP server.

## How to report

Use GitHub private vulnerability reporting on this repository:
Security tab => Report a vulnerability.

Do not open a public issue for a security problem. Say which file or URL is affected and
what you saw. A maintainer replies in the advisory thread.

## Third-party skills

Records that describe third-party skills, tools or models are not an endorsement. The
hub does not audit their code. Read a skill before you install it, and run it with the
least access it needs.
