# Third-party material

Files in this repository that were made by someone else. Each keeps its own licence.

## Fonts

The site under `site/` serves these fonts from its own folder. No font is loaded from another
origin. Each font is the variable `woff2` published in the project's own repository, pinned to
one commit. The file was renamed to drop the brackets; the bytes are unchanged.
