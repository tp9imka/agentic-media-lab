# X API pay-per-usage pricing

`source:docs.x.com/x-api/getting-started/pricing` - source - <https://docs.x.com/x-api/getting-started/pricing>

X's developer page for API pricing: credits bought in the Developer Console, charged per resource read or per write request, with no subscription.
