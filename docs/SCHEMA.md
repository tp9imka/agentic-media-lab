## Data files

Each `data/<kind>/<lane>.json` and `data/concepts.json` is `{"schema_version": 1, "lane": "<lane>", "records": [...]}`. `data/observed.json` is keyed by record id and written only by `tools/enrich.py`.

## Ids and page paths

An id is `<kind>:<slug>`. The slug matches `^[a-z0-9][a-z0-9._/-]*$` and has no `//`, no `__` and no trailing `/`. The page path replaces `/` in the slug with `__`: `tool:remotion-dev/remotion` => `catalog/tool/remotion-dev__remotion.md`.

## Concept

File: `data/schema/concept.schema.json`. One vocabulary entry in data/concepts.json. SKOS ideas in plain JSON. The id never changes; the label may. At most 2 broader concepts. A concept has no licence.

| Field | Type | Required | Allowed | Notes |
|---|---|---|---|---|
| `id` | string | yes | `^concept:[a-z0-9][a-z0-9-]*$` | - |
| `label` | string | yes | - | Preferred label. |
| `alt_labels` | array of string |  | - | Synonyms and acronyms, shown and indexed. |
| `hidden_labels` | array of string |  | - | Misspellings and reader slang, indexed only. |
| `scope_note` | string |  | - | What is in and what is out. |

## Kind-specific fields

Required on top of the shared fields, per `kind`:

| Kind | Also required |
|---|---|
| tool | `url`, `maturity`, `tool_type`, `agents`, `levers`, `cost` |
| model | `url`, `maturity`, `modes`, `access`, `apple_silicon`, `licence_class` |
| source | `url` |
| recipe | `maturity`, `stages`, `video_types` |

A record is marked inactive when `status` is archived or retracted, or `maturity` or `access` is shut-down. It keeps its page and is listed separately in the catalog.

## Evidence badge

One badge per record, derived in this order; the first row that applies wins.

| Tier | Label | When |
|---|---|---|
| `measured` | measured by us | `measured.rung` is one of `measured_rungs` in hub.config.json and `measured.command`, `measured.input`, `measured.commit` are set |
| `quoted-primary` | quoted, primary source read | at least one claim, `checked.depth` is primary-read, no claim has `via`, `source_type` is primary, independent-secondary, vendor-or-author, and `corroboration` is not contested |
| `quoted-secondary` | quoted, not read at the primary source | at least one claim and `checked.depth` is primary-read or skim, but a quoted-primary condition fails; the reasons name which |
| `unverified` | unverified | everything else: no claims, or `checked.depth` is not-checked |

A `downgrade` with a named reason (indirect, inconsistent, tiny-sample, interested-party) moves the badge one tier down. A dead or moved link adds a reason and keeps the tier.
